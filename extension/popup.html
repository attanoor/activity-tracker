Activity Tracker

Checking…

  1. Download ActivityTrackerAgent.exe from the Downloads page of your Activity Tracker site.
  2. Run it. In its setup window enter your setup code and click Connect.
  3. A green T icon appears in the Windows tray (check the ^ overflow area). Then click Check again.

If the tray icon is already green and this still says the agent is not running, another program may be using port 47823, or the browser is blocking local connections. Send your admin the file %LOCALAPPDATA%\ActivityTracker\agent.log.
